# ImageInput

The ImageInput component allows users to upload images. It can be used on its own or as part of a
form.

<Controls />

## How to use it

Render the image with the `image` snippet. It receives the `src` to show, `undefined` while there
is none, and `aria-hidden`, which you should spread onto the image. The
[Avatar](?path=/docs/components-avatar--docs) is made for it:

```svelte
<ImageInput
  label="Upload an image"
  clearButtonLabel="Clear"
  loadingLabel="Uploading"
  src={imageUrl}
  onchange={(file) => upload(file).then((url) => (imageUrl = url))}
  onclear={() => (imageUrl = '')}
>
  {#snippet image({ src, ...attributes })}
    <Avatar {src} alt="" {...attributes} />
  {/snippet}
</ImageInput>
```

Users can pick an image, drop it onto the input or paste it. `onchange` receives the `File` and
the input shows a preview of it. Return a promise to show a loading state until it settles. Refer
to the Stateful story for a complete example.

### Uploading an image

When an ImageInput is used as part of a form, there are two possible patterns for uploading the
image picked by a user:

1. upload the image as soon as the user selected it (`onchange`)
2. upload the image when the form is submitted

If possible, prefer the first approach: APIs tend to expect image URLs, not blobs, so uploading an
image during form submission is likely to require request chaining (a first request uploads the
image to an object storage provider and returns an object URL, a second request sends the object
URL along with other form data to some backend service). If the backend service you're working
with handles object storage, choose the second approach.

### Accepting HEIF image uploads

By default, the ImageInput renders an `<input type="file" accept="image/*" />`. With
`accept="image/*"`, some browsers' file pickers won't allow
[HEIF images](https://en.wikipedia.org/wiki/High_Efficiency_Image_File_Format), the default iPhone
photo format. Override it with the `accept` prop:

- **If your service supports HEIF images**, use `accept="image/*,.heic"` and tell users which
  formats are supported with the `validationHint`. The preview won't work for HEIF images.
- **If your service doesn't support HEIF images**, list the supported types explicitly, such as
  `accept="image/jpeg,image/png"`. Safari converts HEIF images to a supported format; other
  browsers don't.

## Input states

### Existing image

With a `src`, the ImageInput shows a "clear" button instead of the "add" one and passes the `src`
to the `image` snippet. Clicking it calls `onclear`.
