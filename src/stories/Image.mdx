### Fixed ratio

Wrap the image in an [AspectRatio](Components/AspectRatio) to crop it to a fixed shape. The image

## Usage

- **Use it to showcase visual content** and keep it responsive. Do not use unauthorized images from
  external sources.
- **Pass `width` and `height`** with the image's intrinsic size when you know it. The browser then
  reserves the right amount of space before the file arrives, so the page does not jump.
- **Native attributes are passed through**, so `loading="lazy"`, `srcset` and `sizes` work as they do
  on a plain `img`.

## Accessibility

- **`alt` is required.** Describe the information the image conveys, or what it does when it is a
  link or a button. If the image is purely decorative, pass `alt=""` so assistive technology skips
  it.
- **Avoid images of text.** If text in an image cannot be avoided, repeat the same words in `alt`.
