# List

The List component renders an ordered or unordered list. Pass the `<li>` elements as children; the
component styles them, including any lists nested inside.

<Canvas withToolbar={true} of={Stories.Base} />
<Controls />

## Component variations

### Variants

An unordered list renders a `<ul>`, an ordered list an `<ol>`. Choose based on whether the sequence
carries meaning, not on how the markers look.

<Canvas of={Stories.Variants} />

### Sizes

List uses the same type scale as the [Body](Typography/Body) component, so a list can match the copy
around it. The legacy `one` and `two` sizes are deprecated and map onto `m` and `s`.

<Canvas of={Stories.Sizes} />

### Nested lists

Nest a List inside an `<li>` to build a hierarchy. The indentation adapts to the size.

## Accessibility

### Use a list for anything list-like

Screen readers announce how many items a list contains and where the user is within it, which is
information that a sequence of paragraphs or `<div>`s cannot convey. Use a list whenever items
belong together — including navigation links and groups of form controls.

### Keep list items short

Long list items are harder to scan and to keep track of when read aloud. If an item runs to several
sentences, consider whether the content wants to be prose instead.
