# PhoneNumberInput

The PhoneNumberInput component provides a straightforward way for users to type their phone number
in an accurate, consistent format including the country code and subscriber number.

<Controls />

## Usage

Use it when you need to collect a phone number from the user, for contact information, two-factor
authentication or other purposes. The user selects their country code and types the subscriber
number; the component normalizes the number to the
[E.164 format](https://www.itu.int/rec/t-rec-e.164/en) in the bindable `value` and calls `onchange`
with it. Pasting a full number, e.g. `+49 151 1234567` or `0049 151 1234567`, fills in both fields.
Other attributes, such as `name`, go to a hidden input that submits the normalized number with a
form.

```svelte
<script lang="ts">
  let phoneNumber = $state('');
</script>

<PhoneNumberInput
  label="Phone number"
  countryCode={{
    label: 'Country code',
    defaultValue: 'DE',
    options: [
      { country: 'DE', code: '+49' },
      { country: 'FR', code: '+33' }
    ]
  }}
  subscriberNumber={{ label: 'Subscriber number' }}
  name="phone"
  bind:value={phoneNumber}
/>
```

The country names come from `Intl.DisplayNames` in the `locale` you pass, or the browser's.

## Differences from circuit

Circuit's country code is a searchable AutocompleteInput. Ours is a native `select`, as circuit's was
before version 10: its list shows each country's name and code, sorted by name, and the closed select
shows only the code, like circuit's field. Browsers jump to a country when you type its first letters
in the select.

Circuit shows the selected country's flag from its CDN by default. Ours shows no flag unless you pass
the `countryCode.prefix` snippet, which receives the selected `country`. The examples here render
circuit's flag images through it.

`value` replaces circuit's `value` and `defaultValue`. `countryCode.onchange` receives the select's
`change` event and `subscriberNumber.oninput` the input's `input` event; pasting a number only calls
the top-level `onchange`.

## Validations

Use the `validationHint` prop to communicate the expected response to users.

### Invalid

When the user needs to change the value to proceed. This could be due to an incorrect format or an
unsupported country code. The state can be applied to the entire component or only to a specific
field, e.g. in the example below it indicates that only the subscriber number is not valid.

### Warning

When the user is recommended to change the value, but can proceed without doing so. Use it when the
provided value could have unintended side-effects, such as a high cost for international calls.

### Valid

When the user is reassured that the value is valid. Use sparingly, as the PhoneNumberInput component
does not validate that the number is actually in service.

## Readonly

Use the `readonly` prop to indicate that the field is not currently editable, e.g. in a summary or
review screen. The state can be applied to the entire component or only to a specific field, e.g. in
